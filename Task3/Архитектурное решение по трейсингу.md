# Анализ

### Системы, которые необходимо покрыть
Нужно добавить трейсинг при обращении к SHOP API, к CRM API, MES API.
Между CRM API и очередью сообщений.
Между MES API и очередью сообщений.

### Список данных, который нужно добавить в трейсинг
- trace_id, span_id, контекст запроса
- идентификатор эндпоинта
- идентификаторы сущностей
- временные метки
- детали исключений

# Мотивация

Трейсинг помогает быстро находить причины, медленной работы сервиса, почему запрос не выполнился и пользователь не смог оформить заказ, по какой причине запрос "завис".
Трассировка позволяет быстрее узнать с какой ошибкой запрос не выполнился и каковы были параметры запроса. Что позволяет быстрее устранять неполадки и сбои в системе.
Например, пользователь пожаловался, что не смог оформить заказ.
